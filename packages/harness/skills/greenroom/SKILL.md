# Greenroom Review Harness

Use this skill only when Greenroom explicitly starts a Greenroom-owned workflow.
Greenroom owns durable state, consent, validation, anchor semantics, and final
persistence. The harness explores the local repository and returns schema-bound
draft output.

Before acting, read the relevant references in `references/`:

- `concept-primer.md`
- `workflow-rules.md`
- `mcp-guide.md`
- `anchor-rules.md`
- `output-examples.md`
- `repair-behavior.md`
- `read-only-safety.md`

For setup checks, the non-secret smoke resource is described in
`resources/setup-smoke.json`.
