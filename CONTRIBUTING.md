# Contributing to Greenroom

Thanks for your interest in Greenroom!

## Issues are welcome

Bug reports and feature requests are genuinely appreciated — they are the
best way to help right now. Please use the issue forms:

- [Report a bug](https://github.com/jldaniel/greenroom/issues/new?template=bug-report.yml)
- [Request a feature](https://github.com/jldaniel/greenroom/issues/new?template=feature-request.yml)

For suspected security vulnerabilities, please follow
[SECURITY.md](SECURITY.md) instead of opening a public issue.

## Pull requests

Unsolicited external pull requests are not currently accepted. Greenroom is
in an early public phase with an intentionally small maintenance surface, so
changes land through issues and maintainer-driven work rather than direct
external PRs. If you'd like to see something changed, please open an issue
describing it — that's the fastest path to getting it addressed.

(Automated dependency-update pull requests, such as those from Dependabot,
are an exception to this policy.)

## Development

If you're exploring the codebase, the [root README](README.md) covers setup
(`bun install`, `bun run greenroom -- up`), the package layout, and the
verification suite (`bun run verify`).
